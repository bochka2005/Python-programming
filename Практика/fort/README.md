# Поле чудес — README

## Описание проекта
Игра **«Поле чудес»** - это упрощённая версия телевизионной игры "Поле чудес", которая запускается в консоли и 
предназначена для одного игрока. Игрок пытается отгадать случайно выбранное слово, вводя буквы или сразу слово целиком. 
Игра поддерживает уровни сложности, систему жизней и запоминает рекорд игрока. Игра реализована с использованием модульной структуры и упакована в пакет. 
Список слов для игры загружается из текстового файла с расширением .txt, который по умолчанию располагается в папке с пакетом с основными модулями игры.


## Установка
1. Скачайте проект или клонируйте репозиторий:
   ```bash
   git clone https://github.com/
   ```
2. Запустите игру:
   ```bash
   python -m wheel_of_fortune
   ```

## Правила игры
1. Игрок выбирает уровень сложности:
   - **Лёгкий** - 7 жизней
   - **Средний** - 5 жизней
   - **Сложный** - 3 жизни
2. Игроку показывается слово, скрытое символами `■`.
3. Игрок вводит буквы:
   - Если буква есть - она открывается.
   - Если буквы нет - теряется одна жизнь.
4. Можно вводить слово целиком:
   - Если верно - раунд выигран.
   - Если неверно - раунд окончен, все жизни теряются.
5. Если слово отгадано - игрок решает, продолжать ли игру.
6. Игра завершается при окончании жизней или отказе продолжать.
7. Когда игра завершается выводится статистика и обновляется рекорд.
