# Office Tweaks 

**Office Tweaks** — это полнофункциональная консольная утилита для автоматизации работы с файлами. Программа поддерживает два режима работы: интерактивное меню и пакетную обработку через командную строку.

## Основные возможности
*   **Управление каталогом**: Смена рабочей директории.
*   **Конвертация документов**:
    *   PDF → DOCX (используется `pdf2docx`)
    *   DOCX → PDF (используется `docx2pdf`, требуется MS Word)
*   **Сжатие изображений**: Оптимизация JPEG, PNG, GIF с выбором качества.
*   **Умное удаление**: Удаление групп файлов по маске, расширению или подстроке.
*   **Два режима**:
    *   **Интерактивный**: Удобное текстовое меню.
    *   **CLI**: Аргументы командной строки для скриптов и автоматизации.

## Запуск программы

### 1. Интерактивный режим
Запустите программу без аргументов, чтобы открыть меню:

```bash
python office_tweaks.py
```
*Или используйте флаг `-i`.*

### 2. Пакетный режим (CLI)
Используйте аргументы командной строки для выполнения операций без диалога.

#### Справка по всем командам:
```bash
python office_tweaks.py --help
```

#### Примеры использования:

**Конвертация PDF → DOCX:**
```bash
python office_tweaks.py --pdf2docx "C:\Docs\Contract.pdf"

python office_tweaks.py --pdf2docx all --workdir "C:\Docs"
```0

**Конвертация DOCX → PDF:**
```bash
python office_tweaks.py --docx2pdf all
```

**Сжатие изображений:**
Обязательно укажите качество сжатия (`--quality`) от 1 до 100.
```bash
python office_tweaks.py --compress-images all --workdir "C:\Photos" --quality 70
```

**Удаление файлов:**
Требуется указать режим (`--delete-mode`) и шаблон (`--delete-pattern`).
```bash
python office_tweaks.py --delete --delete-mode extension --delete-pattern tmp
```

### Описание аргументов CLI

| Аргумент | Описание |
| :--- | :--- |
| `--workdir` | Указать рабочий каталог для операции |
| `--pdf2docx` | Путь к файлу или `all` для конвертации PDF -> DOCX |
| `--docx2pdf` | Путь к файлу или `all` для конвертации DOCX -> PDF |
| `--compress-images` | Путь к файлу или `all` для сжатия картинок |
| `--quality` | Качество сжатия (целое число 1-100) |
| `--delete` | Включить режим удаления файлов |
| `--delete-mode` | Режим удаления: `startswith`, `endswith`, `contains`, `extension` |
| `--delete-pattern` | Строка или расширение для фильтрации файлов |
| `-i`, `--interactive` | Принудительно запустить интерактивное меню |

## Сборка в EXE

Для создания автономного исполняемого файла (не требует Python у пользователя):

```bash
pyinstaller --onefile --console --name Office_Tweaks office_tweaks.py
```

Готовый файл будет находиться в папке `dist/`.
